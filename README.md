# Drama — automated content creation

Drama is an early-stage project for exploring automated, faceless content production.

## Current status

The repository currently contains a project description and an MIT license. It does not yet include the application implementation, setup instructions or a working content-generation pipeline.

This README intentionally describes the project's direction without presenting planned functionality as completed work.

## Intended direction

The project may develop into a workflow for planning, assembling and preparing short-form content for publication. Any future integrations, generation steps and publishing features will be documented after they are implemented.

## Contributing

Before adding features, document the runtime, dependencies, configuration and a reproducible local run command. Do not commit API keys, account credentials or private media.
